# 像素工坊 PixelStudio

单文件 H5 图片处理工具（Material You 风格），所有处理均在浏览器本地完成，图片不会上传。

## 功能

- 像素级无损裁剪（拖拽 8 个手柄 / 数值输入 / 键盘方向键微调，支持常用比例锁定）
- 旋转、翻转（选区会随画面一同变换）
- 等比 / 自由修改尺寸（解除锁定后的非等比拉伸在调整裁剪或旋转时会被保留），多种重采样算法（高质量模式逐级折半缩小，避免大幅缩小时的锯齿）
- JPEG / PNG / WebP 的 EXIF 读写（含 GPS，快门速度支持 `1/125` 写法），可一键清除隐私信息（BMP / AVIF 导出不含元数据，界面会给出提示）
- JPEG / PNG / WebP / BMP（以及浏览器支持时的 AVIF）导出，有损 / 无损压缩率控制
- 原图与输出结果的拖动对比（对比分隔线也可用键盘左右方向键移动）
- 深色模式与五种动态主题色（原生下拉框、滚动条等控件会同步切换配色）
- 手机端顶部文件信息栏会隐藏，可通过画布工具栏左侧的“更换图片”按钮切换图片

## 注意

- EXIF 文本字段单项上限 8000 字节，超出部分会在导出时被截断，以保证 JPEG 的 APP1 段不超过 64KB。
- 读取到的空白 / 全零拍摄时间（相机时钟未设置时的占位值）会被视为空，不会写入表单。
- 重新锁定宽高比时，输出尺寸会按当前裁剪区域的比例自动还原。
- 拍摄时间除 `YYYY:MM:DD HH:MM:SS` 外，也接受 ISO 8601 写法（如 `2024-05-01T10:20:30Z`，带小数秒 / 时区后缀时仅保留其本地时间部分）。
- 导出的 JPEG / PNG / WebP 会补全 Exif 必需标签（ColorSpace 等）并写入真实的输出像素尺寸（PixelXDimension / PixelYDimension）。
- 仅修改 EXIF 字段（或开关“清空 EXIF”）时会复用上一次已压缩的像素数据，只重写元数据，不再重新绘制与压缩。
- 导出文件名最长 120 个字符，并会避开 `CON` / `NUL` 等 Windows 保留设备名。
- 点击“全图”会解除已锁定的裁剪比例（全图通常不符合预设比例）。

## 使用

直接用浏览器打开 `index.html` 即可，无需构建、无外部依赖。
