# 像素工坊 PixelStudio

采用 Material You 设计的零依赖、单文件 H5 图片处理工具。所有处理均在浏览器本地完成，图片不会上传至任何服务器。

## 功能

- **无损裁剪**：支持手柄拖拽、精确像素输入与键盘方向键微调，内置多种常用比例预设
- **旋转与翻转**：支持 90° 旋转与水平 / 垂直镜像翻转，选区随画面同步变换
- **尺寸调整**：支持等比或自由缩放、百分比滑块、常用分辨率预设及多种重采样算法
- **EXIF 元数据**：支持读写 JPEG / PNG / WebP 的相机参数、拍摄时间与 GPS 坐标，可一键清除隐私信息
- **格式转换与压缩**：支持导出 JPEG、PNG、WebP、BMP（及浏览器支持时的 AVIF），提供有损 / 无损压缩与透明背景填充色选择
- **实时画质对比**：支持原图与输出结果的拖拽分割线对比，实时预估输出体积变化
- **个性化界面**：适配桌面与移动端，内置深浅色模式与五款动态主题色
